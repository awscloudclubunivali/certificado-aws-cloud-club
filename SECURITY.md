# Política de Segurança

## Reportando uma vulnerabilidade ou exposição de dados

Este projeto processa dados pessoais (nomes e emails de participantes de eventos). Se você encontrar:

- Uma vulnerabilidade de segurança no código, ou
- Dados pessoais reais expostos acidentalmente no repositório (histórico de commits, branches, issues, etc),

**não abra uma issue pública**. Reporte de forma privada usando a aba [Security → Report a vulnerability](../../security/advisories/new) do GitHub, ou entre em contato diretamente com os mantenedores do AWS Cloud Club Univali.

Inclua o máximo de detalhes possível: onde o dado/vulnerabilidade foi encontrado e o impacto potencial.

Faremos o possível para responder e corrigir em tempo hábil.
